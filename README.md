# Super Auto Pets · 单机版

一个纯前端的 Super Auto Pets 复刻，**双击 `index.html` 就能玩**。
不需要安装任何东西，不需要命令行，不需要服务器。

---

## 怎么玩

**双击 `index.html`** → 选择模式 → 开玩。

### 两种模式

| 模式 | 玩法 | 经济 |
|---|---|---|
| **🎯 经典模式** | **10 胜**通关、**3 败**出局（平局不算输）。每回合打一支系统生成的对手队伍 | **SAP 式**：每回合固定 10 金，**不累积**；宠物统一 3 金；刷新 1 金 |
| **⚔️ 8 人混战** | 你和 **7 个人机**同场竞技。每回合随机两两配对，输的扣血，**血量归零出局**；活到最后获胜 | **TFT 式**：基础 5 金 + **利息**（每存满 10 金 +1，上限 5）+ **连胜奖励**（分档 +1/+2/+3），金币**累积**；宠物**按星级定价** T1=1 金 … T6=6 金；刷新 2 金 |

### 操作

| 操作 | 说明 |
|---|---|
| 点击商店里的宠物 | 购买 |
| 把商店宠物**拖到队伍指定位置** | 买下并直接放到那个位置 |
| 点击队伍中的宠物 | 选中它 |
| 连点同一只宠物两次 | 出售 |
| 拖动队伍中的宠物 | 调整站位顺序 |
| 点击道具 | 进入选目标状态，再点一只宠物使用 |
| 🎲 刷新 | 重掷商店 |
| ❄ 冻结 | 该位置的商品下回合保留 |
| ⚔️ 结束回合 | 开打！ |
| 战斗中的 0.5×/1×/2×/4× | 调节动画播放速度 |
| ✨ 遗物三选一 | **回合 3/6/9/12…** 会弹出选择，永久生效 |

### 遗物系统

每 3 回合（从回合 3 开始）给你一次**三选一**的机会，选中的遗物**永久生效**，两种模式都有。
8 人混战里 7 个人机会随机拿一个（保证规则对等）。

目前共 **13 种**，分三类：

| 类型 | 遗物 |
|---|---|
| 💰 经济 | 金库（+3金/回合）、钱庄（利息上限+3）、批发商（宠物-1金）、营养师（食物-1金）、当铺（出售+1金） |
| ⭐ 成长 | 训练场（每回合给最前友方+1/+1）、孵化器（升星奖励变 3 个）、星探（商店等级提前 1 回合） |
| ⚔️ 战斗 | 战旗（开战全体+4生命）、獠牙（开战全体+2攻击）、铁甲（开战全体获得椰子）、猎杀标记（开战对敌方最前排 3 伤害）、急救包（开战全体+2生命） |

### 通用规则

- 队伍上限随回合增长：**回合 1-2 最多 3 只、回合 3-4 最多 4 只、回合 5+ 最多 5 只**
- 买**同名**宠物会合成升级：`2 点经验 → 2 级`，`再 3 点经验 → 3 级`（每点经验 **+1/+1**）
- **商店等级**按回合自动解锁：**回合 1→T1、3→T2、5→T3、7→T4、9→T5、11+→T6**
  （商店只会刷出已解锁星级的宠物）
- **升星奖励**（官方规则）：宠物升星时，商店里会出现 **2 个「下一星级」的宠物**供你挑选；
  但**合成到 3 级不触发**

## 战斗机制（引擎的核心）

引擎严格按 SAP 官方规则实现：

1. **攻击是「双方同时互殴」**，不是先手制。
   每个战斗回合，双方最前排的宠物**同时**对彼此造成伤害。
2. **伤害 = 攻击力**，最低 1 点；有西瓜时可减到 0，椰子可完全免疫一次。
3. **阶段顺序**：
   `开战 → 攻击前 → 互殴 → 受伤/阵亡 → 攻击后 → 后排见证 → 回合结束`
4. **宠物阵亡后从队伍移除，后排补位**。
5. **遗言链会递归结算**：一个宠物的阵亡触发的召唤/伤害，可以继续引发新的阵亡。
6. **Perk 只能带一个**（官方规则）：宠物同时只能携带 1 个食物 Perk，新的会覆盖旧的。

## 对手与难度

### 经典模式：官方 Ghost（幽灵）算法

对手队伍按官方 wiki 的 Ghost 规则生成：

- **回合 1**：从 Tier 1 选 **3 只**
- **回合 2+**：选 5 只（不超过当回合队伍上限），并获得**行动点**
- **行动点 = 回合数 × 2 − 4**，每点随机做三件事之一：
  ① 给一只宠物一个食物 Perk　② 给一只宠物 +1 经验
  ③ 给一只宠物 +`floor(回合/4)+2` 点属性（随机分到攻击或生命）

**注意**：官方没有显式难度系数——难度差异来自**行动点的随机分配**（有的幽灵属性堆在一只身上，有的摊得很散），这天然产生强弱差异。

> ⚠️ **本作对行动点打了 `0.4` 的折扣**（`CFG.AP_SCALE`）。因为官方曲线是给「完整 6 tier 宠物池 + 真实玩家快照」设计的，而本作只有 Turtle Pack 61 只、对手全是幽灵，按原版会碾压玩家。实测折扣 0.4 时通关率约 40%（测试 AI 是下限，真人会更高）。

### 8 人混战

- **7 个人机与你使用完全相同的商店规则**（保证公平）
- 每个人机有**随机性格**（`greed` 0.55~0.95）：有人激进花钱、有人攒钱吃利息，天然强弱有别
- 每回合随机两两配对；**人数为奇数时随机一人轮空**（不掉血）
- 扣血 = `基础伤害(随回合增长) + 每个存活敌方单位 1 点`

```

js/game.js          商店 / 经济 / 回合 / 对手生成
js/render.js        公共渲染层（两种模式共用）

js/ui.js            经典模式界面
js/melee.js         8 人混战核心逻辑
js/melee-ui.js      8 人混战界面
```

### 三条关键设计

**1. 引擎输出「有序事件日志」，而不是最终状态**

引擎跑完一场战斗，返回的不是"谁赢了"，而是一串事件：

```js
{ e:'attack', a:uid, b:uid, dmgA:3, dmgB:1 }
{ e:'faint',  t:uid, pos:0 }
{ e:'summon', t:uid, side:0, pos:0, defId:'ZombieCricket' }
```

界面拿着这串事件**逐条播放**，于是血条、动画、召唤都自然发生。
**战斗回放功能是白送的**，8 人模式里 AI 之间的战斗则可以只取结果、丢掉日志（所以 8 人局不会卡）。

**2. 技能是数据，引擎不认识任何具体宠物**

引擎只提供通用原语（`buff` / `hit` / `summon` / `behind` / `ahead` …），
每个宠物的技能写成一小段数据：

```js
Ant: {
  name: 'Ant', cn: '蚂蚁', tier: 1, atk: 2, hp: 2,
  texts: ['阵亡：给随机 1 个友方 +1/+1', '…+2/+2', '…+3/+3'],
  hooks: {
    faint: (g, c) => {
      const t = g.random(g.friends(c.self), 1);
      if (t[0]) g.buff(t[0], c.lvl, c.lvl);
    }
  }
}
```

**加一只新宠物 = 加一条数据，不用改引擎。**

**3. 公共渲染层**

`render.js` 里只有无状态的纯函数（宠物卡、商店槽、道具槽）。
加新玩法时，复制一份 `solo.html` + 写自己的 js 即可，渲染全部复用。

## 加自己的宠物

在 `js/data.js` 的 `PETS` 里加一条即可。可用的 `hooks`：

| 阶段 | hook | 上下文 |
|---|---|---|
| 战斗 | `startOfBattle` | 开战时 |
| 战斗 | `beforeAttack` | 自己即将攻击 |
| 战斗 | `selfAttack` | 自己攻击后 |
| 战斗 | `hurt` | 自己受伤（`c.dmg`） |
| 战斗 | `knockOut` | 自己击倒敌人（`c.target`） |
| 战斗 | `afterAttack` | 自己攻击结算完毕 |
| 战斗 | `aheadAttack` | 前面的队友攻击了 |
| 战斗 | `aheadFaint` | 前面的队友阵亡了 |
| 战斗 | `friendFaints` | 任意友方阵亡（`c.dead`） |
| 战斗 | `friendHurt` | 任意友方受伤（`c.hurt`） |
| 战斗 | `faint` | 自己阵亡（遗言） |
| 战斗 | `friendSummoned` | 友方被召唤（`c.target`） |
| 战斗 | `summoned` | **自己**被召唤 |
| 商店 | `buy` / `sell` / `levelUp` | 买 / 卖 / 升级时 |
| 商店 | `startTurn` / `endTurn` | 回合开始 / 结束 |
| 商店 | `friendlyAteFood` | 友方吃了道具（`c.eater`） |
| 商店 | `friendBought` | 友方被购买（`c.bought`） |

可用原语：`g.buff(pet, atk, hp)`、`g.hit(pet, n)`、`g.summon(side, pos, defId, {atk, hp, lvl})`、
`g.friends(pet)`、`g.foes(pet)`、`g.behind(pet, n)`、`g.ahead(pet, n)`、`g.random(arr, n)`、
`g.givePerk(pet, 'Melon')`、`g.addGold(n)`、`g.stock('Apple', 0)`

## 数据来源与已知简化

- **战斗机制**：依据官方规则实现，并参照 MIT 许可的开源实现
  [`koisland/SuperAutoTest`](https://github.com/koisland/SuperAutoTest) 逐项核对
  （攻击同时结算、触发分层、阵亡塌缩、伤害上下限）。
- **宠物数据**：从官方 wiki（`superautopets.wiki.gg`）抓取的真实数值，
  覆盖当前版本的 364 个宠物，本项目选取 Turtle Pack Tier 1–6。
- **商店等级 / 升星奖励 / Ghost 算法**：均取自官方 wiki「The Basics」与「Ghost」页面。
